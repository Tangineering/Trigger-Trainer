Trigger Discipline Trainer

⚠ Loud alarms. Hold Test sound and set the volume before you start. Keep the phone away from your ears.
  1. Point the muzzle downrange and tap Set downrange. From then on, pointing more than 90° away triggers alarm.
  2. Index finger flat on the frame strip = safe.
  3. Finger off the strip or on trigger = hold still. Any movement sounds an alarm until the finger is back on the strip.
  4. Pull the trigger straight back to fire. Return finger to frame before moving.

180 rule

The 180 check is off until you point downrange and tap Set downrange next to the target. Tap it again any time to reset. If the page is put in the background, downrange has to be set again. Canting the phone doesn't count; only where the muzzle points does.
